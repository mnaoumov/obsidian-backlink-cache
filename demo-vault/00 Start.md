# Start here

Welcome to the [Backlink Cache](https://github.com/mnaoumov/obsidian-backlink-cache/) demo vault.

**Backlink Cache no longer does anything but point to its successor**, [Advanced Metadata Cache](https://community.obsidian.md/plugins/advanced-metadata-cache). The backlink cache it used to keep now lives there, together with more. Since version 3.0.0 this plugin has one job: to ask you to install Advanced Metadata Cache, and once that is enabled, to ask you to remove Backlink Cache itself.

**How to see it:** open [01 Successor suggestion](<./01 Successor suggestion.md>). The notice it describes already appeared when this vault opened.
